# Bilingual Voice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` with the already selected six `openai-codex/gpt-6-luna` workers and Sol orchestration; no model fallback. Steps use checkbox syntax for tracking. This is planning-only; execution requires separate owner review and the independent authorities below.

**Goal:** Deliver a complete native-owned, offline Turkish/English voice turn: deliberate local capture, real ASR, deterministic routing or real local generation, and actual local speech, with visible state and verified cancellation.

**Architecture:** A Rust `VoiceSessionSupervisor` is the sole session/effects owner, with strict public Tauri v1 DTOs, private authenticated worker v2 transport, native-only capture/speech, purpose-bound assets and an inert React mirror. Native macOS arm64 is the first and only support target until each additional platform independently proves its adapter, containment, packaging and offline physical behavior. Real voice acceptance is the complete eight-deliverable dependency chain below; provider traits, fixtures, browser tests or a text-only fallback are not completion.

**Tech Stack:** Existing React/TypeScript/Vite and Tauri 2/Rust; Objective-C `cc::Build` bridges; macOS CoreAudio/AUHAL; exact Whisper and llama native APIs from independently reviewed pinned source-built static libraries; AVSpeechSynthesizer; existing Security.framework owner-authority patterns; Python standard-library source acquisition/build-manifest tooling and verifier tests. No browser media/speech APIs, cloud, shell inference, third-party plugin, runtime CLI/server, new daemon, or speech fallback.

**Spec:** `docs/superpowers/specs/2026-10-06-bilingual-voice-design.md`. The owner has explicitly authorized implementation, bounded acquisition of the two named runtime source archives, the reviewed local source-build route, separate Whisper/Qwen model approvals, local Apple Development + Secure Enclave setup, and owner-activated native tests; each remains separately gated.

## Global Constraints

- Native supervisor owns permissions, owner IDs, effects, deadlines, resources and cleanup; renderer/native IDs are identifiers, never bearer capabilities. Public wire v1 is distinct from private worker v2.
- Canonical renderer facade is `src/platform/voice-client.ts`; native status/snapshot/live records use bounded pull-based `voice_get_status`, not an event channel. Wire `u64` values are canonical decimal strings; raw PCM, arbitrary paths, URLs, model text actions and caller-minted authority never cross public IPC.
- Audio stays native and ephemeral: maximum 30 seconds, mono 16 kHz Float32 (480,000 samples / 1,920,000 bytes canonical utterance); aggregate raw audio <=8 MiB. No silent truncation, auto-relisten, wake word, cloud, persisted transcript/audio or renderer capture.
- Preserve `ModelTransferState::Blocked` and all existing Stage1 five-artifact schemas, IDs, key/binding state, and checks. Voice authority is independent and purpose-bound. No transfer or activation until exact authorization, consent, signed identity and artifact review gates pass.
- Runtime source route: build exact owner-selected Whisper commit `d1be6fde11ac6e0407606b4e42fe72d34add8037` and llama commit `8345f333951c661d166b00e6f9362e553768f292` as static arm64 native libraries only after exact archive digest, signed source tree, mode roster, active build/dependency/license closure, toolchain/recipe, output ABI and whole-descendant isolation are independently reviewed and approved. No CLI inference, runtime network, implicit dependency fetch, or build at ordinary startup. Keep both bundled ggml snapshots separately pinned and compiled; matching version strings do not establish identical sources or authorize cross-linking.
- Deterministic router runs before any LLM; model output is text only. No substring `<think>` filtering: prove pinned non-thinking template/token framing and prevent actual reasoning/control-token payload publication. Literal educational `<think>` text remains readable and inert.
- Speech requires exact selected voice ID and independently established offline/quality evidence; no language/default substitution. Filter verified supported tr/en voices before the 128 supported-catalog cap. Shared OS speech service may be measured but never killed; quota actions may cancel app speech and kill only directly owned workers.
- Snapshot is a logical object, not one frame: pinned begin/page/end transfer, <=65,536-byte frames, <=4,096 UTF-8 text bytes/page, <=128 sequential pages, <=64 pending records, reserved terminal/cancel capacity; atomically assemble <=81,728 text bytes plus bounded metadata. No partial publication or UI/main-thread serialization stall.
- Full automatic transcript routing is allowed only for evidence-eligible ASR. Review/uncertain/mixed/unsupported/language-limited recognition requires explicit edit/language confirmation; no transcript or intent is fabricated.
- Localization includes all user-facing strings independently reviewed in English and Turkish, including native permission text and installer/recovery/errors. Keep browser fixtures clearly non-native; unsupported platforms fail honestly before side effects.
- No product milestone is complete without licensed fixture and physical bilingual/offline/security/resource/cancellation proof. Missing gates are explicit NO-GO, not “scaffold complete.”

## Review Focus

1. **Stale owner, permission, or cancellation races:** Task 2/3/5/7 tests prove late permission, PCM, worker result, synthesis callback or UI ack cannot revive revoked work; cleanup failure never becomes idle.
2. **Cross-webview authority or transcript leakage:** Task 2/7 prove foreign window/origin/generic event listener sees no content and invokes no effect.
3. **Uncertain/negative/quoted Turkish or English command:** Task 4 proves no partial intent; clarification/review or inert model text only.
4. **Framing and size boundaries:** Task 2/7 exercise complete history+transcript+answer > one frame, incomplete/duplicate/wrong-owner page, revision change, and concurrent live events; no partial or stale snapshot wins.
5. **Adversarial worker/model/speech boundaries:** Task 3/4/5/8 prove descriptor authenticity, OS containment, no reasoning/action leakage, correct actual voice, and cancellation while queues/workloads are saturated. Literal quoted `<think>` examples remain readable.
