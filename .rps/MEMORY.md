# Durable project lessons

- Keep microphone selection in Settings only, as explicitly requested. Remember exact per-app input IDs; never change macOS defaults or silently substitute a different source when a saved input is unavailable. Device discovery itself must not capture audio.
- On native capture failure, inspect app-scoped WebKit/CoreAudio logs and the selected/default input before changing CSP or permissions. Permission can succeed while an Aggregate Device fails capture.

- User-triggered local audio visualization is approved, but recording, transcription, upload and automatic/background restart are not. Keep ownership across every permission/resume await, register end handlers early and check track liveness before claiming listening.
- Keep strong references to instrumented MediaStreamTrack wrappers in WebKit fixtures and assert native readyState alongside spy counts; wrapper collection can otherwise erase expando overrides and create false leak reports.

- Choose a native-capable frontend without implementing an agent runtime before there is a real feature need. Stage 1 uses a local demo boundary, not a server.
- Never confuse illustrative telemetry with measured host data. Keep the simulation label adjacent to every such instrument and preserve that distinction in future adapters.
- Validate focus in WebKit, not only Chromium: native mousedown can undo pointerdown focus. App-scoped click capture preserves real button openers; retain the cross-engine regression.
- Treat fully occluded WKWebView captures as inconclusive. Observe native load/window state and get foreground permission before deciding the app is blank; do not weaken CSP to address a capture artifact.
- Use both viewport width and height in acceptance tests. A responsive layout can avoid horizontal overflow but still miss a one-screen desktop intent.
- Keep pending preview work owned by its open interaction. Closing conversation cancels future scripted side effects, while explicit diagnostic runs have independent cancel controls.
- Use docs/rps-alignment.md for current evidence and open gates; docs/voice-reactive-core.md preserves feature history. Owner confirmation that capture works does not certify all native cleanup/performance gates. Browser fixtures do not certify physical capture; automated checks do not certify full accessibility or aesthetics.
- Update PROJECT, README and historical spec/plan supersession links together so fresh agents do not restore removed features or obsolete restrictions. Keep acceptance gaps explicit rather than weakening them.
- Preserve the requested header removal of logo/clock/UI PREVIEW/pause; retain Settings/command-palette pause and reduced motion.
- Distinguish same-version candidates with archive names and hashes; untracked source and a clean git diff are not a commit checkpoint. See docs/rps-alignment.md.
- The approved main surface is compact core + direct composer; use a Workspace drawer for secondary tools. Preserve saved data, not decorative fake panels. See docs/compact-refinement.md.
- Preserve animation identity and phase: removing CSS animations, changing duration, and remounting the core caused verified discontinuities. Keep players and scene state, pause/play timelines and use updatePlaybackRate with a short easing ramp. Profile actual paints rather than adding per-frame DOM counters.
- Pointer opener fixes must exclude keyboard-generated implicit-submit clicks, which can steal focus from the composer. The Enter → conversation → Escape regression covers both engines.
- Exiting Radix layers may consume Escape during replacement mounting even after the next dialog is visible. The app owns the active panel; retain the timing-controlled Workspace/Settings/Conversation regressions and the close guard that prevents retired panels from closing a replacement.
- Treat “plugin” as a trusted compile-time module until an isolated external-plugin runtime, signed packages, capability mediation, resource limits and rollback are independently verified. A Web Worker is not an untrusted-code security boundary.
- Never represent fixed-key XOR, hard-coded keys, or plain SQLite as secure encrypted storage. Do not widen the Tauri command surface until a bounded capability contract, threat model and IPC tests exist.
- Never disable accessibility or other recommended lint categories to make a feature build. Repair the feature or keep it blocked.
- Conversation providers are untrusted async boundaries even when local. Normalize bounded input before dispatch, pass `AbortSignal`, fence every reply/action by request ownership, and retain the scripted offline provider as rollback until a replacement passes resource and privacy gates.
- Local-model evidence must be frozen before transfer and bound to one immutable manifest, run ID, model hash, runtime/source hash, harness version, and machine profile. Recompute raw facts under a strict finite-number schema; never accept self-reported `passed` flags or thresholds.
- Kernel-enforced network denial is the offline proof boundary. Direct-PID `lsof` sampling is only diagnostic and must fail closed; own, account for, terminate, and reap the complete runtime process group.
- Disposable AI probes must retain only allowlisted counters and hashes, never prompt/completion/stderr excerpts or local model paths. Reject path aliases/symlinks, publish with unique no-follow atomic files, and delete staged model/runtime bytes after a failed or partial spike.
- Evidence acceptance must consume an opaque lifecycle receipt derived from real generations; public caller-supplied counters, syntax-only run IDs, or archive self-consistency cannot attest execution. Bind each scenario to an unpredictable handshake generation ID and reject cross-run replay.
- Size bounded response queues to every manifest-valid frame, then use nonblocking overflow handling for excess. A small hidden queue can reject valid bursts or deadlock shutdown even when frame and aggregate limits are correct.
- On macOS, process groups do not contain descendants that create a new session. Default helpers must be unable to fork; fork-permitting profiles are test-only. `sandbox-exec` pathname launch cannot certify production executable identity against a malicious same-UID race, so production requires a signed app-owned helper and designated-requirement verification.
- A local macOS build that must fork cannot claim whole-tree containment from process groups, inherited descriptors, `sandbox-exec`, or launchd alone: a descendant can call `setsid()` and close inherited descriptors. Prefer a digest-pinned prebuilt arm64 runtime, or use a real VM/job boundary, instead of waiving this for trusted upstream source.
- A signed nested-helper finalizer must verify the untouched outer bundle seal before trusting its identity resource, validate one immutable staged artifact against pre-sign hash/size/architecture/link identity, sign that artifact in private staging with empty helper entitlements and hardened runtime, seal its post-sign hash, then sign the outer app with separate exact entitlements.
- Signed-helper acceptance is bound to a recomputed current-source allowlist before and after locked Cargo build, finalization, and verification; a bundle-internal generation value alone is replayable.
- Framed helper EOF is clean only before the next frame begins. Partial frames, malformed terminal data, nonzero child exit, late frames, response overflow, deadline expiry, or unverified temporary-root deletion must fail closed.
- A stage-1 acquisition claim is not executable evidence until one top-level lifecycle recomputes the owner-bound harness manifest, durably burns the one-time capability before network access, owns every transfer through inspection, cleans every retained descriptor-owned role, and only then exposes a sealed receipt publisher. Structural replay must stay labeled and bind the exact authorization digest.
- Cleanup must delete through retained role descriptors before checking their root-directory names. A renamed role can escape path-only cleanup while still containing downloaded bytes; clear the held descriptor, clear the current root, and fail the run if the role identity detached.
- Crash recovery may delete only a workspace whose exact device/inode/UID and random name were durably registered before transfer. Never sweep name-matching directories: a same-user lookalike is not proof of stage-1 ownership.
